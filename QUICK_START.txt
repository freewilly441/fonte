1. OPEN THE PROJECT

   - File → Open → Select: fonte/android

2. BUILD THE APP
   Option A: Using Android Studio
   - Build → Make Project
   - Build → Build Bundle(s) / APK(s) → Build APK(s)
   
   Option B: Using Command Line
   - Open Command Prompt in fonte/android directory
   - Run: gradlew.bat clean build -x test
   - Or use: quick-build.cmd (automated build & deploy)

3. RUN ON EMULATOR
   - Ensure Android emulator is running (emulator-5554)
   - Device Manager → Start emulator
   - Android Studio: Run → Run 'app'
   - Or use adb: adb install app/build/outputs/apk/debug/app-debug.apk

4. TEST THE APP
   - Type a message and click Send
   - App will respond with placeholder messages
   - UI should work smoothly with Material Design 3 styling

================================================================================
  WHAT HAPPENS WHEN YOU BUILD
================================================================================

1. Gradle downloads dependencies (~500MB on first build)
2. Kotlin compiler compiles source files
3. Resource files are processed (layouts, colors, strings)
4. Android Gradle Plugin packages APK
5. APK is generated in: app/build/outputs/apk/debug/app-debug.apk (~5-10 MB)

First build: ~5-15 minutes (downloading dependencies)
Subsequent builds: ~1-3 minutes

================================================================================
  TROUBLESHOOTING
================================================================================

BUILD FAILS - "Could not find android.arch.lifecycle"
→ Check local.properties points to correct SDK:
  sdk.dir=C:\Users\melan\AppData\Local\Android\sdk

BUILD FAILS - "Module not specified"
→ Ensure you're in the android directory:
  cd C:\Users\melan\documents\Aethermark_Systems_LLC\Code_Projects\fonte\android

BUILD FAILS - "Java version incompatibility"
→ Check Java version (need 11+):
  java -version

APK INSTALL FAILS - "No connected devices"
→ Start emulator first:
  • Android Studio → Device Manager → Start emulator
  • Or: emulator -avd Android14 (or your AVD name)

APK INSTALL FAILS - "app conflicts with..."
→ Uninstall first:
  adb uninstall com.fonte
  adb install app/build/outputs/apk/debug/app-debug.apk

For more details, see: BUILD_INSTRUCTIONS.md
