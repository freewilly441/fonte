================================================================================
  DEPLOYMENT FLOW (3 STEPS, ~20 MINUTES)
================================================================================

STEP 1: Download TinyLlama Model (10-15 min)
─────────────────────────────────────────────
Download URL:
  https://huggingface.co/TheBloke/TinyLlama-1.1B-Chat-v1.0-GGML/resolve/main/tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf?download=true

File: tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf
Size: ~690 MB
Format: GGML (ready to use, no conversion needed)

Or use Python script:
  python download_tinyllama.py


STEP 2: Place Model in Android Assets (2 min)
──────────────────────────────────────────────
Create directory:
  mkdir fonte\android\app\src\main\assets\models

Copy model:
  copy "C:\path\to\tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf" ^
       "fonte\android\app\src\main\assets\models\model.gguf"

Verify:
  dir fonte\android\app\src\main\assets\models\
  → Should show model.gguf (690 MB)


STEP 3: Build & Deploy (5-8 min)
────────────────────────────────
Option A: Automated
  quick-build.cmd

Option B: Manual
  cd fonte\android
  gradlew.bat clean build -x test
  adb install app\build\outputs\apk\debug\app-debug.apk
  adb shell am start -n com.fonte/.MainActivity

Launch app and test chat!

================================================================================
  PERFORMANCE PROFILE
================================================================================

Device Requirements:
  • Minimum: Android 8.0 (API 26+)
  • Recommended: Android 10+ (API 29+)
  • RAM: 4GB minimum, 8GB recommended
  • Storage: 1GB free for model + app

TinyLlama Performance (1.1B Model):
  • Model Size: 690 MB
  • Memory Usage: 1.5-2.5 GB during inference
  • Inference Time: 300-500ms per token
  • Single Response (4 tokens): 1.2-2.0 seconds
  • Context Window: Up to 2048 tokens
  • Max Output: 512 tokens per response

First Launch Timing:
  • App startup: ~2-3 seconds
  • Model loading: ~1-2 seconds
  • First inference: 1-2 seconds (includes tokenization)
  • Subsequent: 300-500ms per token

Battery Impact:
  • Idle: Minimal
  • Inference: Moderate (high CPU usage)
  • Estimated: Full conversation session uses ~2-5% battery
